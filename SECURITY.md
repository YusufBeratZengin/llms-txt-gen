# Security policy

Version 0.1.x is the initial supported line. llms-txt-gen reads local files and writes the files you name; it makes no network requests.

Please report vulnerabilities privately through GitHub: open the repository's [Security tab](https://github.com/YusufBeratZengin/llms-txt-gen/security) and choose **Report a vulnerability** (the maintainer must have private vulnerability reporting enabled; if the button is missing, open an issue asking for a private channel, without exploit details). Do not include real credentials or personal data in any report. No response-time guarantee is offered.

A useful report has the version, Node.js version, operating system, a minimal synthetic folder or input, expected versus observed behavior, and, if possible, a proposed regression test.
